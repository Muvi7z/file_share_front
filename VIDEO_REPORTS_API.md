# API жалоб на видео

Фронтенд отправляет жалобы на существующий публичный эндпоинт `POST /api/videos/reports`.

Тело запроса:

```json
{
  "videoId": "uuid",
  "title": "Название видео",
  "reason": "Зависает или повторяет кадры",
  "positionSecond": 20,
  "comment": "Повторяются кадры",
  "status": "open",
  "createdAt": "2026-09-22T12:00:00.000Z"
}
```

Сервер отвечает `200 OK` и возвращает созданную запись с полем `id`. Начальный статус — `open`. Маркер жалобы сохраняется в браузере только после успешного ответа сервера.

При ошибке введённые причина, время и комментарий остаются в открытой форме, чтобы пользователь мог повторить отправку.
