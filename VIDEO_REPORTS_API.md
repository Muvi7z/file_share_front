# API для общих отметок о проблемах

Сейчас фронтенд хранит отметки локально в браузере. Они не отправляются администратору.

Для общих отметок предлагается POST /api/videos/:id/reports:

```json
{"reason":"playback_stutter","comment":"Повторяются кадры","positionSeconds":20}
```

Ответ 201: {"id":"uuid","status":"open","createdAt":"ISO-8601"}.
Причины: playback_stutter, audio_issue, unavailable, other.
Разрешить обычным пользователям; если нужны гости, разрешить анонимные обращения с ограничением частоты.
Автор определяется сервером из сессии. Проверять существование видео, доступ к нему, конечное неотрицательное время, длину комментария до 1000 символов и допустимую причину.

GET /api/admin/video-reports — список обращений для администратора.
PATCH /api/admin/video-reports/:id — статус open/resolved.
В ответах списка видео добавить openReportsCount, не раскрывая автора и текст другим посетителям.

После появления API заменить локальное сохранение в src/VideoProblem.tsx запросом: успех показывать только после подтверждения сервером, при ошибке сохранять текст формы для повторной отправки.
