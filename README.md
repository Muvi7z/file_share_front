# Local Video Vault

Фронт для файлового менеджера видео в локальной сети. Проект сделан на Vite, React и TypeScript.

## Запуск


```bash
npm install
npm run dev
```

На Windows, если PowerShell блокирует `npm.ps1`, запускай команды через `npm.cmd`:

```bash
npm.cmd install
npm.cmd run dev
```

## Что уже есть на фронте

- публичный просмотр видео без авторизации;
- вкладка `Все файлы` с навигацией по папкам как в проводнике;
- отображение пустых папок, если внутри нет видео;
- переключение между плиткой и списком;
- поиск по названию, папке, кодеку и качеству;
- фильтр по доступным папкам;
- отдельная страница видеоплеера;
- админка с логином;
- форма добавления папки;
- список папок с состоянием, количеством файлов и датой сканирования;
- мок API в `src/api.ts`, который потом нужно заменить на реальные запросы к бэкенду.

## Демо-авторизация

Логин может быть любым, пароль должен быть от 4 символов.
